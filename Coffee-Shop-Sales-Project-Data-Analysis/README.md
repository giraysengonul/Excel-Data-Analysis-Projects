# ☕ Coffee Shop Sales Project – Data Analysis (Excel)

This project explores and analyzes sales data from a coffee shop using Microsoft Excel. The analysis provides valuable insights into sales trends, customer behavior, and product performance to support business decision-making.

![Coffee Shop Dashboard](./images/Page1.png)


---

## 📌 Business Questions Answered

1. **How have Maven Roasters sales trended over time?**  
   → Sales were visualized across time periods to uncover overall growth, slowdowns, and seasonality.

2. **Which days of the week tend to be busiest, and why might that be the case?**  
   → Sales volume was grouped by weekdays to detect patterns in customer behavior.

3. **Which products are sold most and least often? Which drive the most revenue for the business?**  
   → Product-level analysis was conducted to identify top-selling and low-selling items, as well as their contribution to overall revenue.

---

## 📊 Key Features

- Cleaned and structured raw sales data in Excel
- Used pivot tables for summarization and comparison
- Created interactive charts to visualize trends and patterns
- Performed frequency and revenue-based analysis at the product level
- Derived insights without the use of code or external tools

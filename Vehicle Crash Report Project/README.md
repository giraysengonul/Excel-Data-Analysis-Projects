# 🚗 Monthly Vehicle Crash Report Automation with VBA Macro

This Excel project automates the monthly reporting of vehicle crash data for a client of a data analytics company. By using VBA macros, the report generation process is streamlined to save time and reduce manual effort.

---

## 📋 Project Overview

The macro-enabled Excel workbook provides answers to critical questions regarding vehicle crash incidents over a 24-hour period, including:

- 🚦 Vehicle Crash Times over 24-hour period  
- 📍 Unique Accident Addresses  
- ⚠️ Total Injured and Dead counts  
- 🔢 Count of Contributing Factors ranked from highest to lowest

---

## ⚙️ Features

- Fully automated report generation with a single button click  
- VBA macros to process raw crash data and summarize key metrics  
- Dynamic tables and charts updated automatically  
- Easy to use for monthly recurring reports  
- Eliminates manual data preparation and report formatting errors

---

## 🛠 Technologies Used

- Microsoft Excel  
- VBA (Visual Basic for Applications) for macro programming  
- Excel tables, pivot tables, and charts for data visualization

---

## 📥 How to Use

1. Open the Excel workbook.  
2. Enable macros if prompted.  
3. Click the **"Generate Report"** button to run the macro.  
4. The report sheets will be populated automatically with updated data summaries.  

---


## 📌 Notes

- Make sure to enable macros in Excel to use the automation features.  
- The macro is designed for data formatted as per the sample dataset; adjustments may be needed for different data sources.
